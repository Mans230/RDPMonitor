Open private panel

Connect this device to Tailscale, open the private HTTPS address and sign in with your passkey using your fingerprint or device lock.

Register new devices on the sign-in screen. A local server administrator must match and approve each request. Passkeys can be revoked locally; no login token is shared through the bot.

Administrator setup and recovery

Configure Tailscale Serve and the exact private hostname locally on the server. The panel listens on loopback only. Keep RDP available for recovery.

Use the local commands private-enable, passkey-pending, passkey-approve and passkey-revoke. Public IP access cannot be enabled here.

Bot & web panel updates

Install validated releases from Mans230/RDPMonitor. Updates preserve configuration and restart the bot and panel. Active backups and system images postpone installation. A dependency change requires manual installation.
